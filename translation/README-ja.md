# 🍵 お茶ライセンス

> 共有は温かくあるべきで、苦くあってはならないからです。

お茶ライセンスは、じっくり蒸らした茶葉の心を持つ、寛容な著作権ライセンスです。クレジットを表示し、ライセンスをそのまま保持し、ついでにお茶を楽しむことを忘れなければ、商用・非商用を問わず、あなたの作品を使用、共有、改変することを他者に許可します。

[お茶ライセンス全文を読む](LICENSE)

## 使い方
1. プロジェクトのルートに [`LICENSE`](LICENSE) ファイルをコピーします。
2. `[Year] [Your Name]` をご自身の情報に置き換えます。
3. `README.md` にバッジを追加します: [![Tea License](https://img.shields.io/badge/license-Tea🍵-brightgreen)](https://github.com/TeaInMud/Tea-License)
4. （任意）ソースファイルの先頭にコメントを追加します: `// Copyright (c) 2026 YourName – Tea License (see LICENSE)`

## なぜお茶なのか？
- **自由に蒸らせ** – あらゆる用途に使えます。
- **タグを残そう** – クレジットを表示し、ライセンスを保持しましょう。
- **苦味なし** – 作者は責任を負いません。
- **ビスケット推奨** – 共有は一緒ならもっと甘くなるから。
