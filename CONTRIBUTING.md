## Contributing to the Tea License 2.0

Thank you for considering a contribution to the Tea License 2.0. This document outlines the process for proposing improvements, reporting issues, and adding translations. The project maintains a professional, respectful environment.

## How to Contribute

### Reporting Issues
If you identify a legal ambiguity, typo, or structural problem, please open an issue on GitHub with:
- A clear title (e.g., "Patent retaliation clause may be unenforceable in some jurisdictions")
- A detailed description and, where possible, suggested wording

### Proposing Enhancements
The Tea License 2.0 is intentionally unique. Before proposing new clauses or changes:
- Ensure alignment with the license's core principles: permissiveness, ethics, attribution, patent peace, weak copyleft, moral rights, the biscuit covenant, and mandatory mediation.
- Open an issue to discuss the idea before submitting a pull request.

### Pull Request Process
1. Fork the repository and create a branch with a descriptive name (e.g., `clarify-section-5`).
2. Make your changes. For translations, place the file in `translations/` using the naming convention `LICENSE.[language code].md` (e.g., `LICENSE.ja.md` for Japanese).
3. Update the main `README.md` and relevant landing page if a translation is added.
4. Submit a pull request against the `main` branch, explaining the rationale and any references.
5. Pull requests require review by the maintainer. Be prepared to discuss the legal and practical implications.

### Translations
All translations must:
- Preserve the original structure and clause numbers exactly.
- Convey the legal meaning faithfully; literal word‑for‑word translation is secondary to legal precision.
- Include the translator's name and date in a comment at the top.
- Not introduce additional restrictions or permissions.

## Code of Conduct
All participants must follow the [Tea House Code](CODE_OF_CONDUCT.md). Professional conduct is mandatory; harassment or disruptive behaviour will result in removal from the project.

## Licensing of Contributions
By contributing, you agree that your contribution will be licensed under the same Tea License 2.0 as the rest of the repository. Your words become part of the license's communal pot.
